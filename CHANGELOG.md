# Changelog — ESP32-C3 LED Clock


## [3.6.0] - 2026-09-21

### BREAKING CHANGE: Конвенция времени RTC
- **RTC теперь всегда хранит время в UTC.** 
- `rtcWriteTime()` принимает локальное время (`struct tm` local) и автоматически конвертирует его в UTC перед записью.
- `initRTC()` использует `timegm()` для прямой интерпретации данных из RTC как UTC.
- Устранены баги с "самолечением конвенции" и сдвигом времени на величину часового пояса (TZ) при старте.
- Упрощена логика сравнения времени из разных источников (NTP vs RTC).

### Исправления (clock_sync.cpp)
- **Fallback на RTC при сбое NTP:** Если NTP недоступен, системное время теперь корректно устанавливается из RTC (ранее оставалось неинициализированным).
- **Запрос внепланового ресинка:** При обнаружении расхождения между NTP и RTC > 2 секунд, дисплей автоматически пересинхронизируется.
- **Tight-wait в CS_WAIT:** Реализован цикл активного ожидания для точного отпускания делителя на границе секунды (устранен джиттер FreeRTOS).
- **Защита от Race Condition:** `phaseCheck()` теперь использует безопасный `clockSyncRequestResync()` вместо прямого вызова `csStart()`.
- **Конфликт с калибровкой:** Если калибровка начинается во время активного ресинка, аппаратная часть корректно освобождается.
- **Проверка `localtime_r`:** Добавлена обработка ошибок преобразования времени.
- **Уменьшение таймаутов:** Таймаут `getLocalTime` уменьшен с 8000 мс до 2000 мс для уменьшения блокировки основного цикла.
- **Обновление `lastRtcWrite`:** Переменная теперь корректно обновляется после записи в RTC в `doNtpSync()`.
- **Немедленная проверка фазы:** `phaseCheck()` вызывается сразу после `clockSyncStartup()`.

### Изменения (rtc_ds3231.*)
- `rtcReadTime()` явно устанавливает `tm_isdst = 0`.
- Версии файлов обновлены до 1.2.0.
